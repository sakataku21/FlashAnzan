# フラッシュ暗算

次々と表示される数字を暗算で足していく、フラッシュ暗算のWebアプリです。

**▶ https://sakataku21.github.io/FlashAnzan/**

## 使い方

1. ユーザー名・桁数・口数・表示時間を設定して「スタート」を押す
2. 3 からのカウントダウンの後、数字が次々に表示される
3. 合計を暗算し、表示された入力欄に答えを入力
4. 「答えを表示」を押すと正解と正誤判定が出る

一度入力したユーザー名は保存され、次回からは入力欄の選択リストから選べます。

## 設定できる項目

| 項目 | 範囲 | 説明 |
| --- | --- | --- |
| ユーザー名 | 任意 | 成績の記録先シート名になります。空のままでも遊べますが、記録は残りません |
| 桁数 | 1〜3 桁 | 1桁なら 1〜9、2桁なら 10〜99、3桁なら 100〜999 の数が出題されます |
| 口数（行数） | 5〜20 口 | 出題される数字の個数です |
| うち4桁の回数 | 0 〜 口数 | 口数のうち何回を 4 桁（1000〜9999）にするかです。0 なら混ざりません |
| 表示時間 | 1〜120 秒 | **全体**の秒数です。この時間を口数で等分して1問ずつ表示します |

出題はすべて加算です。

「うち4桁の回数」を指定すると、口数のうちその回数ぶんだけが 4 桁になり、残りは「桁数」で指定した桁数になります。たとえば 3 桁・10 口・4 桁 3 回なら、3 桁が 7 回と 4 桁が 3 回の計 10 口です。4 桁が何番目に出るかは毎回変わります。

## 数字のフォント

画面に大きく表示される数字（カウントダウン・出題・正答）には、そろばん教材で使われる **abacus2**（Copyright CANON INC. 1997）を使っています。

フォントは `0`〜`9` と `?` の11文字だけに絞り込んで woff2 化し、`index.html` に data URI として直接埋め込んでいます（2,580 バイト）。そのため追加ファイルの配信は不要で、`file://` で開いても字形が崩れません。埋め込みに使ったサブセットは [`fonts/abacus2-digits.woff2`](fonts/abacus2-digits.woff2) に置いてあります。

> 元の abacus2 は `vhea` を伴わない `vmtx` テーブルを含んでおり、そのままではブラウザのフォント検証（OTS）で読み込みを拒否されます。サブセット時に縦書き用テーブルを削除することで解決しています。

## 数字の大きさと配置

カウントダウンと出題中は、数字が**画面全体の中央**に表示されます。

大きさの基準は **4 桁がちょうど表示領域の 7 割に収まるサイズ**です。桁数やカウントダウンによらずこの基準サイズのまま表示するため、字の大きさは常に一定です。

| 表示 | 画面幅に占める割合 |
| --- | --- |
| カウントダウン・1 桁 | 約 17% |
| 2 桁 | 約 35% |
| 3 桁 | 約 52% |
| 4 桁 | 約 70% |

端末や画面の向きは問いません。縦横のうち先に 7 割へ届いたほうに合わせるので、スマホの縦持ちでも PC の横長画面でもはみ出しません。ウィンドウサイズの変更や画面の回転にも追従します。答え合わせの画面では通常のレイアウトに戻り、答えが桁数の多い数（4 桁を混ぜると最大 6 桁）になる場合は画面に収まるよう自動で縮小します。

## 音について

カウントダウン、数字の切り替わり、答え合わせのタイミングで音が鳴ります。音は Web Audio API で合成しているため音源ファイルは不要です。右上のボタンでオン・オフを切り替えられます。

| タイミング | 音 |
| --- | --- |
| カウントダウン 3・2・1 | 短いビープ |
| 出題開始 | 少し高いビープ |
| 数字の切り替わり | 短いクリック音 |
| **正解** | **ピンポン**（呼び鈴のような高→低の 2 音） |
| **不正解・未回答** | **ブブー**（低く濁ったブザーを 2 回） |

ブラウザの自動再生制限により、音が鳴るのは「スタート」を押した後からです。

## スプレッドシートへの記録

答え合わせのたびに、結果が Google スプレッドシートへ自動で追記されます。**ユーザー名ごとにシートが分かれ**、1回の挑戦が1行として記録されます。設定は不要です（記録先はアプリに組み込まれています）。ユーザー名が空のときは記録されません。

| 日時 | 正誤 | 桁数 | 口数 | 4桁回数 | 秒数 | 入力した答 | 正答 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2026/08/11 12:34:56 | 正解 | 2 | 10 | 0 | 5 | 528 | 528 |
| 2026/08/11 12:36:02 | 不正解 | 3 | 15 | 4 | 3.5 | 27204 | 27198 |

「4桁回数」は設定した「うち4桁の回数」、「秒数」は設定した表示時間（全体）です。答えを入力せずに「答えを表示」を押した場合は、正誤が「未回答」、入力した答が空欄で記録されます。

> **列を追加する前に作られたシートについて**
> 見出しが古い構成のままのシートは、次回の記録時に不足している列が自動で差し込まれ、見出しが最新の 8 列に更新されます。6 列（4桁回数・秒数を追加する前）のシートも 1 回で 8 列になります。既存の行は右にずれるだけなので見出しとの対応は崩れず、古い行の「4桁回数」「秒数」は空欄のままになります。

### 記録先を変更する場合

記録先の URL は `index.html` の `ENDPOINT` に直接書かれています。別のスプレッドシートに切り替えるときは、以下の手順で新しい URL を発行して差し替えてください。

1. Google スプレッドシートを新規作成する
2. メニューの **拡張機能 → Apps Script** を開く
3. エディタの中身をすべて削除し、このリポジトリの [`apps-script/Code.gs`](apps-script/Code.gs) の内容を貼り付けて保存する
4. 右上の **デプロイ → 新しいデプロイ** を選ぶ
5. 種類の選択（歯車アイコン）で **ウェブアプリ** を選び、以下を設定して**デプロイ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）を `index.html` の `ENDPOINT` に貼り付ける

### 注意点

- **「アクセスできるユーザー: 全員」** にしないと、ブラウザからの記録が届きません。
- 記録先の URL は `index.html` に書かれており、このリポジトリは公開されています。**URL を知っていれば誰でもこのスプレッドシートに行を追加できます。** 実害があるとすれば「無関係な行が増える」ことで、既存の記録を読み取られたり消されたりはしません（`doPost` は追記しかしないため）。
- Apps Script は CORS ヘッダーを返さないため、アプリは応答を読めません。画面の「送信しました」は**送信を試みたことを示すもの**で、記録の成否はスプレッドシート側で確認してください。
- `Code.gs` を変更した場合は、**デプロイ → デプロイを管理 → 編集 → バージョン: 新バージョン** で再デプロイしないと反映されません。
- シート名に使えない文字（`[ ] : * ? / \`）はアンダースコアに置き換えられます。

## 動作環境

依存パッケージもビルド手順もありません。`index.html` をブラウザで開くだけで動作します。

```
git clone https://github.com/sakataku21/FlashAnzan.git
cd FlashAnzan
open index.html   # Windows: start index.html / Linux: xdg-open index.html
```

入力したユーザー名の一覧はブラウザの localStorage に保存されます。外部に送信されるのは、答え合わせのたびに記録先の Apps Script へ送るデータ（ユーザー名・日時・正誤・桁数・口数・4桁回数・秒数・入力した答・正答）だけです。
