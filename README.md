# フラッシュ暗算

次々と表示される数字を暗算で足していく、フラッシュ暗算のWebアプリです。

**▶ https://sakataku21.github.io/FlashAnzan/**

## 使い方

1. ユーザー名・桁数・口数・表示時間を設定して「スタート」を押す
2. 3 からのカウントダウンの後、数字が次々に表示される
3. 合計を暗算し、表示された入力欄に答えを入力
4. 「答えを表示」を押すと正解と正誤判定が出る

一度入力したユーザー名は保存され、次回からは入力欄の選択リストから選べます。

## 設定できる項目

| 項目 | 範囲 | 説明 |
| --- | --- | --- |
| ユーザー名 | 任意 | 成績の記録先シート名になります。記録しない場合は空でも遊べます |
| 桁数 | 1〜3 桁 | 1桁なら 1〜9、2桁なら 10〜99、3桁なら 100〜999 の数が出題されます |
| 口数（行数） | 5〜20 口 | 出題される数字の個数です |
| 表示時間 | 1〜120 秒 | **全体**の秒数です。この時間を口数で等分して1問ずつ表示します |

出題はすべて加算です。

## 音について

カウントダウン、数字の切り替わり、答え合わせのタイミングで音が鳴ります。音は Web Audio API で合成しているため音源ファイルは不要です。右上のボタンでオン・オフを切り替えられます。

ブラウザの自動再生制限により、音が鳴るのは「スタート」を押した後からです。

## スプレッドシートへの記録（任意）

答え合わせのたびに、結果を Google スプレッドシートへ自動で追記できます。**ユーザー名ごとにシートが分かれ**、1回の挑戦が1行として記録されます。

| 日時 | 正誤 | 桁数 | 口数 | 入力した答 | 正答 |
| --- | --- | --- | --- | --- | --- |
| 2026/08/11 12:34:56 | 正解 | 2 | 10 | 528 | 528 |
| 2026/08/11 12:36:02 | 不正解 | 3 | 15 | 7204 | 7198 |

答えを入力せずに「答えを表示」を押した場合は、正誤が「未回答」、入力した答が空欄で記録されます。

### 設定手順

1. Google スプレッドシートを新規作成する
2. メニューの **拡張機能 → Apps Script** を開く
3. エディタの中身をすべて削除し、このリポジトリの [`apps-script/Code.gs`](apps-script/Code.gs) の内容を貼り付けて保存する
4. 右上の **デプロイ → 新しいデプロイ** を選ぶ
5. 種類の選択（歯車アイコン）で **ウェブアプリ** を選び、以下を設定して**デプロイ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピーする
7. アプリの「スプレッドシートへの記録設定」を開き、URL を貼り付ける

ユーザー名と URL の両方が入力されているときだけ送信します。URL はブラウザに保存されるので、設定は初回だけで済みます。

### 注意点

- **「アクセスできるユーザー: 全員」** にしないと、ブラウザからの記録が届きません。URL を知っている人は誰でも書き込めるため、URL の共有範囲にはご注意ください。
- Apps Script は CORS ヘッダーを返さないため、アプリは応答を読めません。画面の「送信しました」は**送信を試みたことを示すもの**で、記録の成否はスプレッドシート側で確認してください。
- `Code.gs` を変更した場合は、**デプロイ → デプロイを管理 → 編集 → バージョン: 新バージョン** で再デプロイしないと反映されません。
- シート名に使えない文字（`[ ] : * ? / \`）はアンダースコアに置き換えられます。

## 動作環境

依存パッケージもビルド手順もありません。`index.html` をブラウザで開くだけで動作します。

```
git clone https://github.com/sakataku21/FlashAnzan.git
cd FlashAnzan
open index.html   # Windows: start index.html / Linux: xdg-open index.html
```

ユーザー名・記録先 URL はブラウザの localStorage に保存されます。サーバーには送信されません（記録設定をした場合の送信先は、あなた自身の Apps Script のみです）。
