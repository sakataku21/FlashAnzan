# フラッシュ暗算

次々と表示される数字を暗算で足していく、フラッシュ暗算のWebアプリです。

**▶ https://sakataku21.github.io/FlashAnzan/**

## 使い方

1. 桁数・口数・表示時間を設定して「スタート」を押す
2. 3 からのカウントダウンの後、数字が次々に表示される
3. 合計を暗算し、表示された入力欄に答えを入力
4. 「答えを表示」を押すと正解と正誤判定が出る

## 設定できる項目

| 項目 | 範囲 | 説明 |
| --- | --- | --- |
| 桁数 | 1〜3 桁 | 1桁なら 1〜9、2桁なら 10〜99、3桁なら 100〜999 の数が出題されます |
| 口数（行数） | 5〜20 口 | 出題される数字の個数です |
| 表示時間 | 1〜120 秒 | **全体**の秒数です。この時間を口数で等分して1問ずつ表示します |

出題はすべて加算です。

## 音について

カウントダウン、数字の切り替わり、答え合わせのタイミングで音が鳴ります。音は Web Audio API で合成しているため音源ファイルは不要です。右上のボタンでオン・オフを切り替えられます。

ブラウザの自動再生制限により、音が鳴るのは「スタート」を押した後からです。

## 動作環境

依存パッケージもビルド手順もありません。`index.html` をブラウザで開くだけで動作します。

```
git clone https://github.com/sakataku21/FlashAnzan.git
cd FlashAnzan
open index.html   # Windows: start index.html / Linux: xdg-open index.html
```
